# Roadmap

## Implemented in the public edition

- Command, HTTP, and TCP checks with group, component, and suite filters.
- LCOV thresholds and JSON reports.
- Strict profiles, bounded command output, and process-group deadlines.
- Synthetic local fixtures and an optional health profile for the Container Workflow example.

## Next

- Verify native Linux and macOS execution before claiming support.
- Add portable examples for common project-owned test commands.

The dashboard, inventory model, scenario generator, database lifecycle, load testing, and API attack modes are outside this edition. They are not promised features.
